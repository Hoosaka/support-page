# 利用規約・免責事項

この規約はアプリの初回確認画面と「設定 → このアプリについて」に表示されるものと同じ本文です。

## 1. 本アプリと本規約

「対脂肪Busters」（以下「本アプリ」）は、脂肪太り（体脂肪型肥満）の成人のダイエットを支援する参考情報を提供する、広告付きの無料アプリです。疾病の診断・治療・予防や医学的助言を目的とせず、医療専門家による判断の代わりにはなりません。利用者が初回確認画面で本規約に同意したときから、本規約が適用されます。本アプリの使用許諾には、Apple の標準使用許諾契約（Licensed Application End User License Agreement）が適用されます。本規約は同契約を置き換えるものではなく、本アプリ固有の利用条件を補足するものです。使用許諾に関して両者が抵触する場合は同契約が優先しますが、適用される法令により保障される利用者の権利を制限するものではありません。

## 2. 対象者と利用条件

対象は、脂肪太りを自覚している18歳以上の方です。18歳未満の方、標準体型の方、アスリート、疾患のある方、妊娠中・授乳中の方は利用できません。18歳未満の方は保護者の同意があっても対象外です（ストアの年齢レーティングとは別の利用条件です）。使用期間は最長3ヶ月を目安とし、目標に達したら利用を終了してください。体調に異変を感じた場合は直ちに利用を中止し、必要に応じて医師・管理栄養士に相談してください。

## 3. 自分の判断と責任での利用

食事や運動など、本アプリの表示にもとづく行動は、自分の体調や状況を踏まえ、利用者自身の判断と責任で行ってください。表示された数値や評価を優先して無理な行動をしないでください。このお願いは、開発者が法令上負う責任を免除するものではありません。

## 4. 独自の算出と結果の個人差

本アプリは、公表されている統計情報や推定式、食品の栄養情報などを参考に、独自の係数と評価方法を用いて、推奨摂取カロリーに相当する「食べてよい目安」、最低摂取ライン、点数・Tier、シミュレーション体重などを算出します。これらは本アプリ独自の参考値であり、公的な判定や実測値ではなく、個人に適した摂取量や安全性を保証するものでもありません。体重などの変化には、体質・年齢・生活習慣・記録内容などによる個人差があり、特定の減量結果や効果を保証しません。出力結果をどのように利用するかは、利用者個人が判断してください。算出に使う入力項目、計算式・係数、参照した資料の名称と参照先、推定上の限界は、アプリ内のヘルプに記載しています。参照資料にもとづく部分と、本アプリ独自の調整・評価は区別して説明しています。
