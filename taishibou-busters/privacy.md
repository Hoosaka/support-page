# プライバシーポリシー

iPhoneアプリ「対脂肪Busters」｜施行日: 2026年9月9日｜あいびさま製作委員会（Aivisama Production Committee）

[サポート](support.html)｜[利用規約](terms.html)

あいびさま製作委員会（以下「当委員会」）は、iPhoneアプリ「対脂肪Busters」（以下「本アプリ」）における利用者の情報の取り扱いについて、個人情報の保護に関する法律、電気通信事業法（外部送信規律）その他の関係法令および App Store のガイドラインに従い、次のとおり定めます。

## 1. 基本方針

- 本アプリは、脂肪太りの成人のダイエットを支援する参考情報を提供するアプリです。アカウント登録はなく、当委員会は利用者の記録を受け取るサーバーを持ちません。
- 利用者が入力した記録（食品・食事・運動・設定・写真）は、利用者の端末の中にだけ保存され、当委員会に送信されません。
- 本アプリは広告の表示と商品検索のために外部のサービスを利用します。これに伴って端末から外部へ送信される情報は「4. 外部送信について」に記載します。

## 2. 本アプリが扱う情報と保存場所

| 情報 | 内容 |
|---|---|
| 記録データ | 登録した食品（名前・栄養成分・分類）、食べた記録、運動の記録、食品の写真（端末内で縮小して保存） |
| 設定 | スタート体重・ゴール体重・ゴール日、基礎代謝の設定値、生活習慣の区分、消費の調整係数と基準点（「今の体重に合わせる」を使った場合）、表示や通知の設定、初回確認への同意状況 |
| 取得しない情報 | 氏名、住所、電話番号、メールアドレス、生年月日・年齢、身長、性別、位置情報、連絡先、ヘルスケア（HealthKit）のデータ。基礎代謝の早見表は年齢・身長・性別を画面で見比べるためのもので、入力・保存しません。 |

これらはすべて端末内（本アプリ専用の保存領域）にのみ保存されます。端末の設定で iCloud バックアップや iTunes／Finder バックアップが有効な場合は、iOS の仕組みによりバックアップに含まれることがあります。

## 3. 端末の機能の利用

| 項目 | 内容 |
|---|---|
| カメラ | 栄養成分表示・バーコードの読み取りと、食品写真の撮影に使います。読み取り（文字認識・バーコード検出）は端末内で処理し、画像を外部へ送信しません。 |
| 写真 | 写真ライブラリから選んだ画像だけを本アプリに取り込みます。ライブラリ全体にはアクセスしません。 |
| 通知 | 食事の入力を確認する通知を、設定した時刻に端末内で表示します（ローカル通知）。通知のために情報を外部へ送信しません。 |
| ウィジェット | ホーム画面のウィジェットは端末内の記録を表示するだけです。 |

## 4. 外部送信について

電気通信事業法の外部送信規律にもとづき、本アプリの利用に伴って利用者の端末から外部の事業者へ送信される情報、送信先、利用目的を公表します。

### 4-1. 広告の表示（Google AdMob）

| 項目 | 内容 |
|---|---|
| 送信先 | Google LLC（Google AdMob／Google Mobile Ads SDK） |
| 送信される情報 | 端末に関する情報（機種、OS のバージョン、言語、画面サイズなど）、本アプリの識別子とバージョン、IP アドレス（おおよその地域の推定に使われることがあります）、広告の表示・タップなどの操作情報、SDK の動作に関する診断情報。本アプリは App Tracking Transparency（トラッキングの許可）を求めないため、広告識別子（IDFA）は利用されず、利用者を追跡するパーソナライズ広告は行いません。 |
| 当委員会の利用目的 | 本アプリ内に広告を表示し、表示回数・収益を計測するため（本アプリを無料で提供・運営する費用に充てます） |
| 送信先の利用目的 | 広告の配信、広告の表示・クリックの計測、不正な広告操作の検知・防止、サービスの改善（詳細は Google の [広告に関するポリシー](https://policies.google.com/technologies/ads?hl=ja) および [プライバシーポリシー](https://policies.google.com/privacy?hl=ja)） |
| 広告成果の計測 | Apple の SKAdNetwork の仕組みを通じて、広告経由のインストール数が個人を特定しない形で広告主に集計されることがあります。 |

### 4-2. 商品検索（Google 検索と商品ページ）

「商品検索」機能を使ったときだけ発生します。使わなければ送信されません。

| 項目 | 内容 |
|---|---|
| 送信先 | Google LLC（Google 検索）、および検索結果から利用者が開いた商品ページの運営者（メーカー・販売店など） |
| 送信される情報 | 利用者が入力した商品名またはバーコード番号（検索語）、閲覧したページの URL、IP アドレス、ブラウザに関する情報（本アプリ内のブラウザは Safari 相当の情報を名乗ります）、閲覧に伴う Cookie。商品を保存するときは、そのページの内容と商品画像を本アプリが取得します。 |
| 当委員会の利用目的 | 商品の栄養成分表示と商品画像を見つけて、食品の登録を簡単にするため |
| 送信先の利用目的 | 各サービスの提供、アクセス解析、広告などの各社の目的（各社のプライバシーポリシーに従います。Google については上記のポリシーをご覧ください） |

### 4-3. Apple（App Store・iOS）

本アプリのダウンロード・更新、端末の「解析データを共有」設定にもとづくクラッシュ報告、端末の設定にもとづくバックアップは、Apple の仕組みで行われ、[Apple のプライバシーポリシー](https://www.apple.com/legal/privacy/jp/)が適用されます。当委員会が Apple から受け取るのは、個人を特定しない集計データ（ダウンロード数、クラッシュの統計など）のみです。

> 当委員会は、上記のほかに利用者の情報を収集したり、解析ツールや SNS の SDK を組み込んだりしていません。

## 5. 利用目的

- 本アプリの機能（記録、目安や点数の計算、シミュレーション体重の表示、通知、ウィジェット）を端末内で提供するため
- 広告を表示し、本アプリを無料で運営するため（4-1）
- 商品検索により食品の登録を簡単にするため（4-2）
- お問い合わせに対応するため（お問い合わせで受け取った内容は、回答と記録の目的にのみ使います）

## 6. 第三者への提供

当委員会は、「4. 外部送信について」に記載した外部サービスの利用を除き、利用者の情報を第三者に提供しません。ただし、法令にもとづく開示要請があった場合はこの限りではありません。当委員会は利用者の記録を保持していないため、記録データを第三者に提供することはありません。

## 7. 保存期間と削除の方法

- 端末内の記録・設定・写真は、利用者が本アプリを削除するとすべて消去されます。記録は本アプリ内で個別に削除することもできます。
- 設定の「データの引っ越し」で書き出した JSON ファイルの保管・削除は、利用者ご自身で行ってください（写真はファイルに含まれません）。
- 広告や商品検索に伴って外部の事業者が取得した情報の保存期間と削除は、各社のポリシーに従います。Google の広告設定は [広告設定ページ](https://adssettings.google.com/)から確認・変更できます。
- 当委員会のサーバーには利用者の情報が保存されていないため、当委員会への削除依頼は不要です。お問い合わせでいただいた情報の削除を希望する場合は、下記の連絡先までご連絡ください。

## 8. 安全管理

本アプリの記録は端末内に保存されるため、端末のパスコード・生体認証などの保護設定が安全管理の基本になります。書き出したファイルを他の人と共有したり、共有の端末で本アプリを使ったりする場合は、記録の内容にご注意ください。

## 9. 未成年の方について

本アプリは 18 歳以上の方を対象としており、18 歳未満の方はご利用いただけません。当委員会は利用者の年齢や個人を特定する情報を取得していません。

## 10. プライバシーポリシーの変更

法令の改正や本アプリの機能変更に応じて、本ポリシーを変更することがあります。変更後の内容はこのページに掲載し、利用者に重要な影響がある変更はアプリ内でもお知らせします。
